# 飞牛音乐助手实施计划

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付可安装的音乐助手 FPK，让飞牛桌面窗口通过同源网关打开现有音乐 Web 服务。

**Architecture:** FPK 管理 Python 标准库 Unix Socket 代理，透传到 8765。后端通过 ASGI root_path 识别网关入口，返回按入口设置 base 的网页；前端保留 history 路由并从 baseURI 解析 API 与路由基址。

**Tech Stack:** FastAPI、Starlette、Vue 3、Vite、Bash、Python 标准库、fnpack 1.2.3。

## Global Constraints

- 应用标识 `MUSICASSISTANT`；显示名“音乐助手”；版本 `1.0.0`。
- 网关前缀 `/app/MUSICASSISTANT`，上游 `127.0.0.1:8765`，Socket `app.sock`。
- 代理只透传字节，后端识别前缀；现有根路径访问继续可用。
- 使用蓝色音符 SVG 及 64/256 像素 PNG，不引入运行时图像依赖。
- 不改用户已有 `config.yaml` 和本地歌单清单，不安装应用、不替换运行中的服务。用户后续已授权整理并提交 GitHub，提交仅包含本次功能源码、图标、测试和文档，构建产物留在本地。
- 当前 checkout 已有用户改动，直接在当前授权工作区完成并逐项核对 diff。

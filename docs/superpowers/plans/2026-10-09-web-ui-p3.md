### 飞牛歌单

- 未配置引导、歌单列表/名称筛选、独立详情路由、创建空歌单或创建时导入已完成单曲任务；同名歌单支持补充。
- suggest 的曲目/专辑/艺人/歌单四组；最多 200 首完整曲目搜索，按 guid 勾选追加。
- 追加支持飞牛曲目 guid、当前服务中的已完成单曲任务、容器绝对路径。后端严格检查任务状态/类型/目标库。
- 显示新增/重复/未匹配数量和路径；追加时提示等待扫描的耗时。进行中的写操作阻止页面跳转。
- 名称通过 URL 编码传递，后端匹配支持斜杠；飞牛毫秒时长转为秒后显示。小屏曲目卡片、桌面表格。

### 扫码登录

- QQ 独立实现 ptlogin → OAuth → QQConnectLogin；网易使用现有 musicdl weapi 加密工具获取/检查 qrcode key。本地 `qrcode` 生成网易 SVG，QQ 返回平台 PNG。
- 创建/查询/取消端点需鉴权；会话内存有效期 180 秒、最多 16 个。响应仅包含不透明会话 key、图片、状态；凭证留在服务端。
- 前端无重叠轮询、已扫码确认提示、网络重试、过期刷新、关闭取消、成功 900ms 后关闭。其他配置草稿保留。
- 确认成功后保存搜索/下载/解析 cookies 并热应用；保留来源启用开关，QQ 重置保活种子并保留设备。保存失败明确提示并在会话中重试。
- 协议按公开接口资料独立实现，没有引入其他项目的登录模块或 AGPL 代码。

协议资料：[QQ 二维码参数](https://github.com/ylw1997/qqmusic-api/blob/master/docs/apis/get-qq-login-qr.md)、[QQ 登录接口资料](https://l-1124.github.io/QQMusicApi/reference/modules/login/)、[网易二维码 key](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/master/module/login_qr_key.js)、[网易扫码检查](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/master/module/login_qr_check.js)、[qrcode SVG](https://github.com/lincolnloop/python-qrcode)。

### 移动端

- 导航抽屉支持焦点约束、Esc、打开时锁定滚动、关闭后恢复焦点；切回桌面宽度时自动关闭。
- 配置保存栏避开底部导航及安全区域；扫码弹窗与曲目列表适应小屏。
- 小屏表单字号 16px 避免 iOS 聚焦缩放，按钮/标签触控区域增大。

## 页面使用反馈修正（2026-10-09）

- 搜索与榜单使用 Pinia 保存当前登录会话的数据、勾选、关键词/数量与排序。路由卸载不再清空结果或取消榜单解析；解析进度在其他页面继续轮询，完成后保留。退出登录/密钥改变时清理会话状态；刷新网页后重新开始。
- 搜索文件大小支持升序/降序，未知大小固定在末尾；下载提交回传完整曲目，避免长期保留结果时仅 id 缓存过期。
- 默认来源统一取运行配置；后端、工作区 YAML 和镜像模板初始值均为 QQ/酷狗/网易/千千/咪咕/酷我六源。设置提供“使用常用六源”，保存后同步搜索页，其他候选不默认勾选。已有挂载配置和用户手动临时选择继续受尊重。
- 榜单默认网易云，QQ 放在后面；桌面表头及移动端均可一键全选全部结果，包含尚未展开的曲目。榜单、单曲任务及专辑清单显示文件大小；新任务记录实际文件字节数，历史从已有文件记录补齐。
- 只读查询部署中的飞牛接口确认：目录字段仅 guid/name/coverId/createdAt/updatedAt，无 trackCount；详情 size=1 返回 total=2、list 长度=1。公共列表改取详情 total；缺总数时分页统计，单个数量失败返回未知，不影响其余歌单。详情返回后也更新卡片数量。

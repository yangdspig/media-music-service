日期：2026-10-08。接续 Kimi Code 会话 `session_f79e111a-e691-4c61-8899-f86de1222aaa`，以 P1 提交 `88a5b15` 为代码基线；设计沿用用户提供的九页 HTML（Vue 3 + Tailwind 4、深青色、顶栏导航、移动端卡片/抽屉/底部导航）。MoviePilot 插件与镜像瘦身仍独立暂缓。

## 已实现

- `web/src/views/ChartsView.vue`：QQ/网易平台切换、榜单目录、可下载曲目解析、限量或全榜、勾选或整榜提交。
- `web/src/views/PlaylistsView.vue`：动态可用歌单源、同步解析长耗时提示、耗时回显、分页展示与全列表选择、下载选项。源参数使用真实客户端名；不虚构后端未提供的歌单标题、创建者与播放量。
- `web/src/views/AlbumsView.vue`：搜索/详情双栏、官方多碟曲目、显示名覆盖、下载源与体积选项、异步轮询、manifest 分数分布/逐曲原因、归档结果与失败曲重搜。本地 singles 复用单列无评分；整辑先下载再选目标库/合集/覆盖归档。
- `web/src/views/LibraryView.vue`：命名库目录分页浏览、曲目选择填表、替换/清理/迁移/回填四操作。清理、迁移、回填均先预览，再用保存的参数确认执行；改范围会使预览失效。替换没有 dry_run，直接提交前确认。
- 共享组件：曲目卡片/表格、下载对话框、专辑清单、归档对话框、运维结果与可键盘操作的模态框。
- 任务页保留本次服务的已完成任务，提供详情/匹配清单与归档入口；修正取消接口返回 false 仍报成功的问题。搜索支持从失败曲链接预填关键词。
- 修复 P1 匿名进入被路由守卫送回登录的问题：先调用真实 API 验证，当前标签页保存匿名通行状态，401 清理状态并回登录。

## 后端补充

设计中的库目录树与评分摘要原先没有读取接口，因此补两条只读 API；搜索、下载、归档与维护复用既有业务函数。

- `GET /api/v1/library/entries`：命名库白名单、库内相对路径、一层分页、不跟随符号链接、不返回文件内容。
- `GET /api/v1/downloads/{task_id}/manifest`：只读内存任务登记的清单，限制在任务目录并核对任务 ID。
- `tests/test_webbrowse.py`：新增 7 项测试，覆盖分页/命名库、绝对路径与越界、符号链接、清单归属/缺失/格式及鉴权。
